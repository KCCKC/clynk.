Blynk-Compatible REST API Reference

Use standard HTTP GET/POST requests from curl, Python, ESP32, or webhooks. Drop-in compatible with existing Blynk endpoints.

GET POST /api/blynk/update

Updates one or more virtual or physical pins in real-time.

Example URL:
http://localhost:3000/api/blynk/update?token=demo_token&pin=V0&value=25.4
Multi-Pin Batch URL:
http://localhost:3000/api/blynk/update?token=demo_token&V0=25.4&V1=58.2&V2=1
GET /api/blynk/get

Retrieves the current state of a specified pin.

Example URL:
http://localhost:3000/api/blynk/get?token=demo_token&pin=V0
GET /api/blynk/history

Fetches timestamped historical telemetry datastreams for charts and analytics.

Example URL:
http://localhost:3000/api/blynk/history?token=demo_token&pin=V0&limit=50
